# 📝 LLM and prompt engineering evaluation for Information Extraction

To feed an open database of archaeological interventions from a
raw-document dataset, a pipeline with the use of an LLM for the extraction of
structured information is wanted.

[🌐 The related project](https://magoh.cfs.unipi.it/)

This repository contains the code which defines some prompt engineering models
to achieve this task. It will also allow identifying which NLP layers should be
added in the pipeline to enhance the correctness.

The definition of the accuracy metrics will also be discussed in documentation
of this repository.

## 📁 Source code

All the source code is inside the [`./prompt_enhancing/`](./prompt_enhancing/)

The prompt engineering work to generate the prompt lists to be tested is
achieved in this project using the [`DSPy` framework](https://dspy.ai/).
